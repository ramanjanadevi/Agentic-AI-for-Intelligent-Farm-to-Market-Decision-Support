# 🌾 Agenti-AI for Intelligent Farm-to-Market Decision Support

An AI-powered decision-support platform designed to help farmers make smarter decisions across the complete **farm-to-market journey** — from crop selection and soil analysis to cultivation planning, market insights, and selling support.

## 📌 Project Description

**Agenti-AI** is an intelligent AI-powered agricultural decision-support platform developed to assist farmers throughout the complete farm-to-market process.

The system combines **Artificial Intelligence, Machine Learning, agricultural data, weather information, soil and nutrient analysis, and market insights** to provide practical recommendations for better farming decisions.

Instead of providing information through a single feature, Agenti-AI follows a **multi-agent approach**, where different AI-driven components focus on different stages of farming and work together to provide useful insights.

The platform helps farmers answer important questions such as:

* Which crop is suitable for my soil?
* What are the soil and nutrient conditions?
* What farming resources are required?
* How can weather conditions affect cultivation?
* What are the current market trends?
* When and where should the farmer consider selling the produce?

The goal is to make agricultural decision-making **simpler, smarter, and more accessible to farmers**.

## 🎯 Objective

The main objective of Agenti-AI is to develop an intelligent platform that supports farmers in making **data-driven decisions from crop selection to market selling**.

### Key Objectives

* Recommend suitable crops based on soil and environmental conditions.
* Analyze important soil and nutrient parameters.
* Provide weather-based farming insights.
* Support cultivation and resource planning.
* Use multiple AI agents for different farming decisions.
* Provide market trend and price-related insights.
* Support farmers in making informed selling decisions.
* Provide an easy-to-use AI assistant for farmers.

---

## 🚀 Key Features

### 🌱 AI-Based Crop Recommendation

Recommends suitable crops using soil and environmental parameters such as nitrogen, phosphorus, potassium, temperature, humidity, pH, and rainfall.

### 🧪 Soil & Nutrient Analysis

Helps understand soil conditions and nutrient levels to support better crop selection and cultivation planning.

### 🌦️ Weather-Based Farming Insights

Uses weather-related information to provide useful insights that can help farmers plan cultivation activities.

### 🚜 Resource & Cultivation Planning

Provides guidance related to cultivation requirements and farming resources.

### 🤖 Multi-Agent AI Decision Support

Different AI-driven components focus on different stages of the agricultural decision-making process and provide combined insights.

### 📈 Market Trend & Price Insights

Provides market-related information to help farmers understand price trends and make more informed decisions.

### 🛒 Farm-to-Market Selling Support

Supports farmers beyond cultivation by providing insights for planning the selling stage of their agricultural produce.

### 💬 Farmer-Friendly AI Assistant

Provides a simple interface where farmers can interact with the system and receive understandable agricultural guidance.

## ⚙️ How to Run

### 1. Clone the Repository

```bash
git clone <your-github-repository-url>
```

### 2. Open the Project Folder

```bash
cd Agenti-AI
```

### 3. Create a Virtual Environment

```bash
python -m venv venv
```

### 4. Activate the Virtual Environment

**Windows:**

```bash
venv\Scripts\activate
```

### 5. Install Required Packages

```bash
pip install -r requirements.txt
```

### 6. Configure MySQL

Create the required MySQL database and update the database configuration in the Flask backend according to your local MySQL setup.

### 7. Run the Application

```bash
python app.py
```

### 8. Open in Browser

```text
http://127.0.0.1:5000/
```
